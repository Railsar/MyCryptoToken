# 🚀 RocketToken (RKT)

RocketToken — это новый BEP-20 токен на сети Binance Smart Chain, созданный для децентрализованных приложений, гейминга и DeFi-экосистемы.

## 📜 Общая информация

- **Название**: RocketToken  
- **Тикер**: RKT  
- **Сеть**: Binance Smart Chain (BSC)  
- **Стандарт**: BEP-20  
- **Общее количество**: 1 000 000 RKT

## 🔐 Контракт (примерный)
> Контракт ещё не развернут. Адрес будет добавлен после деплоя.

## 🛠 Функции

- Mint (создание новых токенов владельцем)
- Совместим с DEX (PancakeSwap и другие)
- Основан на стандарте OpenZeppelin

## 💱 Как купить (после развертывания)

1. Перейдите на [PancakeSwap](https://pancakeswap.finance/)
2. Вставьте адрес контракта (будет позже)
3. Обменяйте BNB на RKT
